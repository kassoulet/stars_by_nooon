STARS – Wonders of the world

A faithful JavaScript reimplementation of STARSv2.EXE, the MS-DOS demo by Noooon (1995): a 16-channel module soundtrack, env-mapped morphing 3D objects, a voxel terrain, feedback tunnels and a lot of palette tricks, all running in 320×200 / 256 colours. The original code was unpacked and reverse engineered, then each effect was ported to plain JS (canvas + a software rasterizer) and checked pixel by pixel against the original machine code.
