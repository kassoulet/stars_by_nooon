# partd (main 0x196..0x1ab): morphing 3D object with animated bump/texture + palette crossfade
Entries: init 0xa14d (at pos>0x3500), wait pos>0x4500, loop 0xa0ca, cleanup 0xa346; timer callback 0xa4ac (0x4abec). Resources: 20 (palette B), 22 (palette A), 21/23 (256x256 textures, only the left 64 columns of the top 128 rows are used), 24 (morph object 'B!' magic byte 3 = 0: 529 verts, 968 faces, 10 extra key frames), 25 (background 64000, = flip bg).
lib3d: mode 15, shift 3, dist 0x64, env map makeEnvMap(ramp@0x9df0, dl=4), sqrt table rebuilt before the object is added, flags 0 (sorted), camera and rot = 0. gs and ds are the SAME 256x256 buffer (0xa04e/sel 0xa052: 0x79801 sets gs, loop start copies the selector into [0x558dc]); the (b-4)<<2 buffer built in init is dead.
Texture buffer: 8 tile frames (0x2000 B = 64x128): T0 = res23, T7 = res21, T1..6 = T0 + ((T7-T0)*i>>3) (signed byte diffs). Tile (w>>3) is repeated 4x horizontally, 2x vertically into the 256x256 buffer every time 0xa530 runs. Palette = A + (((B-A)*w)>>6), w in 0..63 ([0xa076]).
Object: x,y,z,ax,ay,az interpolated (idiv 0x152, trunc) between 6 path keys (0xa082), key counter 0..0x151 / key 0..5 (callback). Morph: anim struct 0x9fa0 (shift 6, steps 63, 34 key indices, advance count 0x21 keys), weight table 0x9e80 = identity; callback advances the step, 0x78ffe (lib3d.morph) runs after the render each frame.
Timeline (t = [0xa046], +1 per tick/frame; frame loop: palette script with t, vsync/tick, DAC write if flagged, flip, object path, render, morph):
 t<0x40 fade in: DAC = B*t>>6 (16-bit logical shr). 0x40..0x436 DAC untouched (B*63/64), tile = frame 7 (set at loop start with w=63).
 0x437..0x82d: DAC = A+(B-A)*w/64 and tile frame w>>3 every frame; w starts 63 (dw=0 -> set to -1 on the first frame of this phase), bounces 63->0->63 (dw negated when w hits 0 or 0x3f).
 t>=0x82e: tile still follows w, DAC = B*bx>>6, bx = 0x3f-(t-0x82e) (jumps from the A/B mix to B); when bx<=0 the loop ends after finishing that frame: t=0x86d, 0x86e = 2158 frames, palette black at the end.
Start: palette black on the first frame (DAC written with 0 at t=0). The loop only begins after pos>0x4500 (frame() returns true without drawing until then; vram cleared in init, palette = whatever the previous part left). Duration 2158 frames = 30.8 s.
Music/beat not used. Rows 0,198,199 of vram stay 0 (render clips).
