# parti (stone torso + mirror reflection) -- web/parts/parti.js
Main: `call 0x16d86` (init, after clearing VRAM), wait pos>0x6c00, `call 0x16f7c` (loop), `call 0x174bd` (cleanup). Loop ends by itself at tick t=0x98f (2447 ticks ~ 35 s) via [0x17081] (or order>0x82, never reached). Start = pos 0x6c01 (loop), duration 2447 frames.
* Resources: 42 palette (6-bit, scaled), 29 texture gs = (b>>1)+0x60, 43 ds map = ((b-4)<<3)&255 (also (b-4)>>1 copy, unused), 44 initial 256x256 mirror target, 45 object A (morph magic 0 file, drawn static, mode 2), 46 object B (mode 20, + copy C pristine), 47 background (dword add 0xe6e6e6e6 with carry, row 0 zeroed).
* Setup: dist 0x12c, shift 1, env map makeEnvMap(ramp@0x16c20, dl=2) +0x20 on every byte. B faces: first 329 w0=0 (warp type), next 130 w0=1 (2-attr type). A start (-2048000,0,-6144000), B (0,0x113000,0xffdc1000).
* Script on t (=ticks, [0x16d56]): <0x40 palette fade-in (pal*t>>6); 0x40: full palette; <0xa0 B rises (y=0x113000*(1-e/0x60), ay=0x800*(1-e/0x60)); <0x130 B spins (ay -= 0xc per tick), wave amp 200->0; <0x1f0 amp=sin*..>>5; >=0x1f0 waves(): B.ax, wx, wz, amp from sin table (`SIN[(a-0x400)&0xfff]`, wz without the -0x400); >=0x2e0 flag7f=1 (A drawn, A and B move per tick, caps in tick()); >=0x640 flag 2 (A.x += 0x2ba, B.x -= 0x5c1); >=0x910 palette fade-out (pal*(0x98f-t)>>7), flag end at t=0x98f. 
* Per frame: flip (0x78905), wave vertices 177..241 of B from pristine C (y += amp<<4, x += wx, z += wz), env map +0x20 on a 16-row band at row amp+0x88 (if |amp|<100; undone after), if flag7f: copy res44 to 256x256 target, mirror image of B (pos x>>1, z=0xffda8000 (B.z is permanently set to it), ay'=0x800-ay) drawn in **mode 21** into the target (new in lib3d: 0x54548 warp + 0x52e96 type-1 faces, 256 wide), then A drawn in mode 2 with the target as env map; then B in mode 20; band undone.
* lib3d additions (additive): `V_T2_320/V_T2_256` + parametrised `tri2/spans2` (0x52e96 + span 0x5324f: verified 400/400 random triangles), `rasterMode21`, `MODES[21]`, `L.tgt` (render target). 0x54548 (`V_WARP256`) still mismatches 2/400 random triangles with y>=205 (outside the 200-row screen use here).
